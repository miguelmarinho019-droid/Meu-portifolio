Meu nome é Miguel Dias.
Esse site demonstra algumas habilidades que pude desenvolver na minha trajetória até aqui que vão desde o básico em python, até html e css.
O que utilizei para montar ele foi o VScode como IDE, Github para a publicação do repositório e no final fiz a publição também no Github pages.
